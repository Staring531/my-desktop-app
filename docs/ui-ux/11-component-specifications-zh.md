# 组件规格

- 阶段：3 — Design Tokens 与核心组件系统，用户批准门禁 2
- 日期：2026-11-20
- 状态：用户于 2026-11-20 连同 Token 基线一并批准。该批准不绘制页面，也不授权应用代码。
- Token 来源：`tokens/design-tokens.json`
- 表面：已接受的清单 S-01 到 S-08。Q-04 仍然开放，因此这套组件没有确认对话框。
- 英文 `11-component-specifications.md` 是规范文本。本文件是对照译文。

共同键盘规则：Tab 按视觉顺序移动。焦点在主要按钮上时，Enter 和 Space 都会激活它。在 S-06 按 Escape 回到 S-05，并且不写入。Escape 关闭 S-08 的通知，并且不写入。焦点是 `semantic.color.focus` 的 2 px 环。每个控件都有可见的文字标签。状态不只靠颜色。

## C-01 窗口外壳

一个窗口对应一个会话。区域：标题行、一个请求外壳打开另一个未绑定窗口的安静控件、当前表面，以及 C-08 和 C-09 的位置。打开另一个会话不复制电子邮件或未发送的编辑。投影带有时区名称时，外壳显示只读的时区名称。Token：底色、标题字体、内边距、无阴影。

状态：未绑定、已绑定，以及 S-07 的不可用状态。S-07 保留外壳并显示 C-08 的不可用结果；它不提供创建操作。

用于每个表面。不要做成导航栏、主题控件，或在同一窗口里放第二个会话。

## C-02 按钮

统一高度 `component.button.height`。变体：

| 变体 | 外观 | 用途 |
|---|---|---|
| 主要 | 强调色填充，白字 | 该表面上唯一的前进命令：绑定、创建团队、接受、保存 |
| 安静 | 底色上的文字，发丝线可有可无 | 打开另一个会话、拒绝、取消、关闭 |
| 危险 | 底色上的危险文字 | 投影允许时的移除、删除、解散 |

禁用的按钮留在原处，使用辅助文字，并且不提交。进行中是同一个按钮，标签改为进行中的动词；没有旋转指示。一个表面只有一个主要按钮。

## C-03 文本字段

电子邮件、标题和地点用单行。描述用多行，边框和文字 Token 相同，高度按正文行高增长。标签在字段外面。不可用或被拒绝的值由 C-08 说明，字段边框改为 `semantic.color.text-danger`。失败不会清空已填写的值。2026-11-20 的文字修正：这个结果是 C-08。C-09 仍然只是写入者通知。

## C-04 时钟字段

开始或结束，使用投影给出的那一个时区的钟面时间。操作者输入时间；字段不提供日历。缺省、不存在和含糊的结果回到 C-08；含糊的字段再配上 C-05。时区不能在这里编辑。

## C-05 选择

一对带文字标签的单选项。两种用途：事件可见性，团队可见或仅自己可见；以及含糊时钟的较早或较晚。两个时钟都含糊时，先给出开始时间的选择。发生时刻没有预选项。方向键在组内移动。该组自己不提交。

## C-06 记号

一个 16 px 的几何记号加上一个词，都使用 `component.mark.text`。

| 含义 | 记号 | 词 |
|---|---|---|
| 忙碌 | 实心方块 | Busy |
| 空闲 | 空心方块 | Free |
| 团队可见 | 实心方块 | Team |
| 仅自己可见 | 空心方块 | Only you |

忙碌和空闲不是绿色和红色。团队可见和仅自己可见不是两种色相。同一个实心方块在忙闲板上可以表示忙碌，在事件上可以表示团队可见；词是区分依据，两个区域不把记号混在同一个列表里。

## C-07 数据行

成员、邀请和事件共用一种行结构。槽位：记号或空白、主要文字、辅助文字，以及投影允许的零个或多个安静或危险按钮。最小高度 `component.row.min-height`，行与行之间是发丝线。选中的事件行增加浅色底和 2 px 前导条。溢出的文字截断，完整文字进入无障碍名称。行本身不导航；它的操作按钮才会。

成员行显示所选时刻的忙碌或空闲。事件行显示可见性、标题和时钟标签。邀请行只对维护者出现，并且只提供投影允许的取消操作。

## C-08 结果

发出命令的表面上的一行或两行文字。角色：成功、拒绝、校验、无访问、记录不可用。成功用主要文字。拒绝和校验用危险文字。文字立即出现，时长为 `semantic.motion.feedback`。它不是独立页面，也不是吐司提示。

## C-09 通知

S-08 的写入者通知。表面底色、发丝线、主要文字，以及一个安静的关闭按钮。层级 `component.notice.layer`。关闭它不会改变记录。S-07 使用 C-08 而不是这个通知，因为该状态会保留到日后批准的修复出现。

## 样本陈列

这些是供审阅的样本，不是页面布局。

| 样本 | 组成 |
|---|---|
| 主要按钮和安静按钮 | 强调色填充的 “Save” 旁边是安静的 “Cancel” |
| 危险按钮 | 底色上的危险色文字 “Dissolve” |
| 文本字段 | 标签 “Title”，空的表面字段，发丝线边框 |
| 时钟字段 | 标签 “Start”，时区名称用辅助文字，不是选择器 |
| 选择 | “Team” 和 “Only you”，操作者选择前都不预选 |
| 记号 | Busy、Free、Team、Only you，各为一个方块加词 |
| 数据行 | 一行成员：实心方块、“Busy”、姓名，没有第二种颜色 |
| 结果 | 字段下方的危险文字 “That email cannot be used.” |
| 通知 | “A writer already exists.” 加上安静的 “Dismiss” |
