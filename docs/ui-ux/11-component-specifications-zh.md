# 组件规格

## 目的
为已批准页面清单所需的组件定义可复用 UI 契约。这是设计规格，不代表必须新建组件库。

## 组件契约模板
每个组件记录：
- ID/名称、用途、用户任务和适用角色。
- 结构/插槽及内容层级。
- 变体、尺寸和已批准 Token 依赖。
- 状态：默认、悬停、键盘焦点、激活、禁用、加载、成功/错误，以及适用时的破坏性状态。
- 输入、输出、事件/命令语义和校验/反馈行为。
- 键盘操作、焦点顺序/管理、无障碍名称/描述和对比度。
- 桌面窗口缩放/溢出行为。
- 使用指南、不适用场景和反模式。
- 使用该组件的页面/流程/PRD AC。

## 候选组件类别
仅在 Stage 0 和页面清单确认后确定：应用外壳/导航、按钮、文本/邮箱/日期/时间字段、选择器/可见性控件、事件行/卡片和忙闲指示、成员/邀请项、对话框、反馈/通知、加载/空/错误/无权限状态。

## 一致性规则
符合契约时优先复用现有组件。页面不得在没有理由记录的情况下创建近似重复组件。共享组件变更必须分析所有使用页面的影响。页面使用前必须定义组件状态。
