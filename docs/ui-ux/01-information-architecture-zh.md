## 1. 导航原则

- 一个桌面窗口是一个会话。另一个会话是另一个窗口，不是第二个团队，也不是另一台电脑。
- 窗口能显示的内容是其已绑定邮箱的投影。窗口不接收整份存档再隐藏字段。
- 导航停留在该投影之内。被邀请人没有成员目的地。active 团队的 `no-access` 投影没有创建团队的目的地。
- 产品目的是根据成员的日程事件查看当前成员何时忙碌或空闲。成员目的地因此把忙闲板和可见事件放在同一个工作区。
- 维护者操作只在投影标明该操作者是维护者时出现。它们不是另一个应用。
- Version 1 没有 Website、Admin、API、登录、设置、主题、日历、仪表盘、个人资料或通知中心目的地。
- 没有时区目的地。C-01 方案 A：窗口显示投影附带的那一个操作系统时区。操作者不能另选时区。

## 2. 提议结构

该结构供接受。若接受，它替换先前包含日历式视图的候选树。

```text
桌面窗口（一个会话）
├── 未绑定
│   └── S-01 绑定本会话
├── 已绑定，记录不存在或已解散
│   └── S-02 创建团队
├── 已绑定，记录为 active，邀请投影
│   └── S-03 仅此邀请
├── 已绑定，记录为 active，no-access 投影
│   └── S-04 不能查看团队
├── 已绑定，记录为 active，成员投影
│   └── S-05 团队工作区
│       ├── 某一时刻的忙闲
│       ├── 可见事件
│       └── 仅当该操作者是维护者时的维护者操作
├── 从 S-05 进入的事件任务
│   └── S-06 创建或编辑一条事件
│       └── 发生次数选择是 S-06 的状态，不是另一个目的地
└── 壳层提示，不是团队目的地
    ├── S-07 记录不可读
    └── S-08 已经有写入者（显示在拥有窗口的进程上）
```

`再开一个会话` 从正在运行的窗口壳层发起。它打开一个新的未绑定窗口。它不带走当前邮箱或未提交的编辑。

## 3. 按角色可达的目的地

| 投影 | 窗口可以显示 | 窗口不显示 |
|---|---|---|
| 未绑定 | S-01 | 团队数据、创建、邀请、事件、忙闲 |
| 记录不存在或已解散，且已绑定 | S-02 | 名册、事件、邀请、忙闲 |
| active 邀请 | S-03，仅该邀请 | 名册、事件、忙闲、其他人的邀请 |
| active 且 no-access | S-04 | 创建、名册、事件、邀请、忙闲 |
| active 成员 | S-05，编辑时再加上 S-06 | 其他成员的仅自己可见事件；除非该操作者是维护者，否则不显示待处理邀请 |
| 身为维护者的 active 成员 | S-05 的维护者操作，以及对所有者已不是当前成员的保留团队可见事件，在 S-06 中做托管编辑 | 更改该保留事件的可见性；移除或指定自己 |
| 唯一成员 | S-05 内的解散操作 | 仍有其他成员时解散 |

已移除的邮箱仍留在其打开的会话上。下一次投影是 S-04；若该邮箱已有待处理邀请，则是 S-03。窗口不会被改绑到另一个邮箱。

## 4. 成员工作区里有什么

S-05 是一个工作区，含三个区域：

1. 忙闲。每个当前成员一行。查看的时刻从当前时间开始，并可移到某条事件的开始或结束。查看者自己的行计入自己的团队可见和仅自己可见事件。其他行只计入该成员的团队可见事件。区间为半开。已结束事件不使当前时刻忙碌。
2. 可见事件。每条团队可见事件的全文，包括已结束事件和该成员加入前创建的事件，以及该成员自己的仅自己可见事件。每一行带有用于编辑或删除的事件 id。待处理邀请只对维护者出现在该工作区，每条是被邀请邮箱。
3. 投影允许的操作。当前成员可以为新事件或自己可以编辑的事件打开 S-06。维护者可以邀请、取消一条待处理邀请、指定另一名当前成员，以及移除另一名当前成员。唯一成员可以解散。普通成员不能做这些名册操作；被拒绝的尝试留在 S-05，记录不变。

S-06 为一条事件收集可见性、标题、地点、说明、开始和结束。创建时必须有可见性和标题。修改时，除非该钟点被编辑过，或正在为它补选发生次数，否则省略该钟点。成功路径没有重复控件，也没有全天控件。只读时区名是投影中的时区。

## 5. 提交接受的结构选择

| 选择 | 提议 | 本草稿不选择 |
|---|---|---|
| 成员落地 | S-05 打开时先呈现忙闲区域，可见事件在同一工作区。 | 单独的日历产品，或只以日程落地。 |
| 事件编辑 | S-06 是从 S-05 进入的任务目的地。没有成功命令就关闭它时，回到 S-05，已存储事件保持不变。 | 在忙闲板上再存一份事件副本。 |
| 维护者工具 | 它们是 S-05 的一个区域，只对维护者显示。 | 单独的管理应用。 |
| 破坏性确认 | 本基线不把它当作目的地。删除、移除和解散是允许表面上的操作。是否出现确认步骤仍是 Q-04。 | 必需的确认页。PRD 没有要求确认页。 |

## 6. 排除的目的地

| 排除项 | 原因 |
|---|---|
| 日历 | PRD 不要求。事件是允许看到的事件列表，不是日期格。 |
| 时区选择器 | C-01 方案 A 和已批准的技术契约。 |
| 登录、邮箱证明、设置、主题 | 在 Version 1 之外。 |
| Website、Admin、API 页面 | 不是 Version 1 界面。 |
| 提醒或通知中心 | AC-027。 |
| 第二个进程的工作区 | 没有拿到锁的进程退出。它没有目的地。 |
