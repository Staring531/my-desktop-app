# 交互规格

每个控件必须说明目的、角色、前置条件、输入、校验、命令边界、成功/失败、取消行为和追溯关系。

## 必须定义的交互
- 按 BR-1/BR-2 规范化和校验邮箱。
- 创建事件时明确选择可见性。
- 标题必填、起止时间顺序、本地时间缺口/歧义处理、保留未修改时间瞬间。
- 保存失败/取消不改变已存储数据。
- 仅创建者可编辑/删除；已移除成员保留的团队可见事件适用 PRD 规定的维护者有限权限例外。
- 只有维护者可邀请/取消/交接/移除；只有唯一成员可解散团队。
- 移除/解散需破坏性确认，但确认不构成授权边界。
- 区分待处理、已完成、被拒绝和失败操作。
- 必要时防止意外重复提交，但不得改变命令语义。

## 反馈分类
字段校验指出字段和修正方式。领域拒绝不得泄露隐藏数据。权限拒绝不得暴露无权操作/数据。操作失败必须说明未完成，不得把未提交值显示为已保存。仅在命令完成后显示成功。

## 时间输入
定义本地时区上下文、夏令时缺口行为、歧义时间的显式选择、未修改时间瞬间的保留，以及按查看者本地时区显示。
