## 1. 原则

1. 已批准 PRD 决定用户可见行为。本分析不增加能力、角色、流程或业务规则。
2. 已批准 Technical Design 决定架构、进程边界、数据归属、持久化和安全。
3. Version 1 的界面是一台电脑上的一个桌面应用、一份本地团队记录。
4. Website、Admin、API 不是 Version 1 的界面。
5. 不引入登录、邮箱验证、多团队、跨设备同步、提醒、重复事件、全天事件、主题偏好或其他已排除行为。
6. 本文是分析，不是实现授权。不改应用代码、不安装依赖、不编辑 Implementation Plan。
7. 已确认需求、提案、假设和待确认问题分开。未确认提案不是用户决策。
8. 后续 UI/UX 文档可以把已接受的页面、组件和交互追溯到 PRD 与技术契约。本阶段只建立初步映射。
9. 本次就绪审阅之后，现行流程是 System-First：结构，然后已批准的视觉方向，然后已批准的 Token 和核心组件，然后页面设计，然后验证和评审。本阶段不启动该顺序。
10. Linear 只作为视觉参考。不复制其品牌资产，也不增加产品专属能力。

## 4. 前端技术与约束

桌面界面技术栈来自 `apps/desktop/package.json` 和 `electron.vite.config.ts`：

- Electron 35 和 electron-vite 3。
- React 19 和 React DOM 19，由 Vite 6 渲染。
- TypeScript 5.8。
- 渲染层别名 `@renderer` 指向 `apps/desktop/src/renderer/src`。
- 没有安装路由、组件库、CSS 框架、图标包或状态库。

界面必须遵守的已批准技术约束：

- 渲染进程不可信。它不发送操作者邮箱、受信任时区、代际或创建事件的 id。
- `bind` 只能发送请求的邮箱。`openSession` 不发送邮箱。
- 每个窗口有一个由主进程分配的会话。
- 主进程推送该会话的投影。界面不接收整份存档再在本地过滤。
- 每个投影包含 `record`：`absent`、`active` 或 `dissolved`。已绑定会话只有在记录不存在或已解散时才能创建团队。active 加 `no-access` 不是创建状态。
- 可见事件包含 `id`。修改和删除使用该 id。
- 忙闲板调用领域函数 `busyAt`。渲染进程可以导入该函数，不能导入其他领域导出。忙闲按正在查看的时刻计算，包括稍后的“现在”，不冻结在推送里。
- 只有操作者改了某个钟点，或正在为刚才被要求的字段补选发生次数时，才发送该钟点。
- 成功路径的界面不提供重复或全天模式。
- 结果码显示给发出命令的会话。其他会话看不到未提交字段。
- 取消编辑或关掉发生次数选择不写入。
- Version 1 在主进程读取一个操作系统 IANA 时区。渲染进程不提供该时区。

## 10. 设计依赖

- 只有用户审阅本分析之后，Stage 1 才能描述导航。
- 事件编辑依赖时间端口已批准的发生次数结果。该依赖包尚未安装。设计可以点名 `earlier` 和 `later`，而不选定视觉样式。

- 随权限变化的控件依赖投影里已经规定的字段：操作者、是否维护者、`record`、名册、邀请和可见事件。它们不依赖渲染进程对照存档文件自行判断角色。

## 11. 风险、冲突和待确认问题

### 需要用户确认的冲突

**C-01. AC-042 与一台电脑的一个时区。**

- PRD AC-042 说，两名成员的设备处于不同时区，他们查看同一时刻时，对所有者是否忙碌的判断一致，并且各自看到自己当前设备本地时区的钟点标签。
- 随技术设计一起批准的 TD-001 把一份记录留在一台电脑上，不同步到另一台电脑。已批准的应用设计在主进程读取一个操作系统 IANA 时区。渲染进程不能提供受信任时区。因此这台电脑上的两个会话在同一时刻共用一个时区。
- 影响：如果不修改 Technical Design，Version 1 的页面无法同时如实呈现两个不同设备时区的查看者；时区选择器会与当前契约冲突。
用户于 2026-11-20 选择方案 A。PRD 正文和技术设计都没有修改。

- Version 1 界面显示主进程读取的那一个操作系统时区。
- 忙闲仍按绝对时刻判断。这台电脑上的两个会话在同一时刻共用该时区。
- 钟点标签使用该时区在每个时刻上的偏移。
- 两个同时存在的设备时区不是 Version 1 的页面。没有时区选择器。
- AC-042 中“是否忙碌”的一致判断仍在范围内。其中“各自的设备时区”不实现为两个同时打开的窗口。

用户先前对 AC-024 的选择仍然是 TD-001：另一名成员是另一个本地会话，或稍后查看同一记录。这里不重开该选择。
