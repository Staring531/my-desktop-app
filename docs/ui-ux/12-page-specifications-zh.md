# 页面规格

## 目的
描述已批准组件和 Token 如何组合成每个已批准页面。本文件不得创建新页面或产品行为。

## 单页面契约
- 页面 ID、名称、状态、角色、权限和前置条件。
- 主要用户目标及相关用户流程 ID。
- 布局区域、层级、信息密度、内容和桌面窗口约束。
- 组件清单及组件规格引用。
- Semantic/Component Token 引用；不得使用任意视觉数值。
- 适用的初始/加载/有数据/空/错误/拒绝/禁用/成功状态。
- 交互入口/出口、校验、取消、命令结果和反馈。
- 键盘/焦点/无障碍行为。
- PRD 需求/AC 和 Technical Design 追溯。
- 待确认问题、假设、偏差和用户决策。

## 页面一致性
共享导航、间距、字体、表面和反馈模式必须保持一致。页面特例必须说明理由并接受评审。没有已批准需求时，不得创建个人资料/设置/通知中心等界面。
