## 2. 每个表面可以发送的命令

| 表面 | 可以发送 | 不得发送 |
|---|---|---|
| S-01 | 带请求邮箱的 `bind`；打开另一个会话的壳层请求 | 操作者、时区、代际，以及成功绑定前的团队命令 |
| S-02 | `createTeam` | 邮箱、时区或代际 |
| S-03 | `acceptInvite`、`declineInvite` | 名册或事件命令 |
| S-04 | 任何会写入的命令都不发送 | `createTeam`、事件命令 |
| S-05 | 仅在投影允许该操作者时：邀请、取消、指定、移除、解散，以及打开 S-06 | 另一个会话的投影；操作者不是维护者时的待处理地址 |
| S-06 | 针对当前打开事件的 `createEvent`、`modifyEvent`、`deleteEvent` | 渲染进程自造的事件 id；时区；操作者没有编辑的钟点，刚被要求补选发生次数的那个字段除外 |
| S-07、S-08 | 任何会写入的命令都不发送 | 替代团队或第二个写入者 |

## 4. 顺序说明

IMP-020 点名了绑定、另一个会话、一条事件、发生次数选择和 `busyAt`。S-03、S-05 上的维护者操作和解散是 PRD 所要求的，因此列在这里。它们不在该任务点名的渲染列表中。Implementation Plan 没有被修改。若本清单被接受，以后的就绪复核可以就这些表面提议计划增量。本阶段不写该增量。
