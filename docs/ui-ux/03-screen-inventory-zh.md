## 规则
只有评估任务连续性和无障碍后才能合并/拆分。记录被排除候选项及原因。每个获批页面都必须映射 PRD 需求或说明其为必要壳层/状态。未经批准不增加 Dashboard、设置、个人资料、认证或通知中心。
