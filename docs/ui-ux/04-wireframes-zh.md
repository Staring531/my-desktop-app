# 线框设计

## 目的
在视觉样式之前确定布局、层级和任务顺序。线框是提案，不得暗中决定产品问题。

## 覆盖范围
覆盖所有获批页面或说明合并理由；桌面窗口尺寸；主要/次要/破坏性/禁用操作；键盘焦点；校验和恢复；适用的空/加载/成功/无权限/错误状态。

## 单页面模板
1. 页面 ID/名称和角色/前置条件。
2. 主要任务和辅助信息。
3. 布局区域和层级。
4. 控件及操作语义。
5. 校验和反馈位置。
6. 状态变体。
7. 键盘/无障碍行为。
8. PRD AC 和 Technical Design 引用。
9. 待确认问题及备选方案。

## 保真度顺序
文本草图 → 低保真线框 → 用户审阅信息架构/任务顺序 → 结构基线获接受后再做高保真视觉规格。

不得把静态生成图片作为可编辑布局、组件语义或交互行为的唯一事实来源。源文件必须可审阅、可维护。
