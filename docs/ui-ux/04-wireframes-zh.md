## 共用外框

每个正在运行的窗口都使用 C-01。初始窗口是现有的 1200×800 Electron 窗口。更窄或更矮的窗口保持同一条纵向堆叠并滚动表面。行内操作放不下时折到文字下方。不会变成第二列导航，也不会变成日历。

```text
+------------------------------------------------------------------+
| 标题                         已知时显示时区    [打开另一个会话]   |
|------------------------------------------------------------------|
| 仅在显示 S-08 时出现 C-09 通知                                   |
| 当前投影的表面                                                   |
| 发出命令的控件下方的 C-08 结果                                   |
+------------------------------------------------------------------+
```

`打开另一个会话` 是每个表面上的外壳安静按钮。它打开一个新的未绑定窗口，不复制电子邮件，也不复制未发送的字段。焦点顺序从该按钮开始，然后按表面从上到下移动。S-01 除外：邮箱字段在先，该按钮跟在表面之后。

S-08 是已经拥有记录的那个窗口上的这条通知。没有拿到锁的进程直接退出，没有外框。关闭通知不会写入。

## S-01 绑定

操作者：未绑定的窗口。主要任务：为这个会话输入电子邮件。

```text
绑定这个会话
电子邮件
[________________________]
[绑定]
结果行
```

焦点：电子邮件，绑定。空的或被拒绝的电子邮件留在这张草图上；结果说明拒绝原因，字段保留已输入的值。绑定成功后，表面换成 S-02、S-03、S-04 或 S-05。绑定是唯一的主要按钮。

## S-02 创建团队

操作者：已绑定的电子邮件，记录不存在或已解散。命令不发送电子邮件。

```text
创建团队
这个会话是 {电子邮件}
[创建团队]
结果行
```

焦点：创建团队。成功后表面换成 S-05。拒绝则留在这里。

## S-03 这份邀请

操作者：待处理邀请，且不是当前成员。没有名册、事件或忙闲。

```text
邀请
{受邀电子邮件}
[接受]  [拒绝]
结果行
```

焦点：接受，拒绝。接受是主要按钮。接受成功进入 S-05。拒绝成功且不再有访问权时进入 S-04。命令失败则留在这里。

## S-04 没有团队访问权

操作者：团队仍在活动，已绑定的电子邮件既不是成员，也没有待处理邀请。

```text
没有团队访问权
{电子邮件} 不能查看这个团队。
```

没有写入按钮，也没有创建操作。日后若投影里出现给这个电子邮件的待处理邀请，表面换成 S-03。

## S-05 团队工作区

操作者：当前成员。忙闲板在最前。事件和维护者区域跟在同一表面里。只有一个主要按钮：新建事件。

```text
团队
正在查看 {投影时区中的时刻}                         [现在]

成员
[■ 忙碌]  {电子邮件}                [设为维护者] [移除]
[□ 空闲]  {电子邮件}

事件
[■ 团队]     {标题}  {开始–结束}  [看开始] [看结束] [编辑]
[□ 仅自己]   {标题}  {开始–结束}  [看开始] [看结束] [编辑]
[新建事件]

待处理邀请，仅维护者
{电子邮件}                                              [取消邀请]

邀请，仅维护者
电子邮件
[________________________]                              [邀请]

[解散]   仅唯一成员
结果行位于发出该命令的位置下方
```

`设为维护者`、`移除`、邀请、取消和 `解散` 只在投影允许该操作者尝试时才渲染。普通成员看不到这些控件。`移除` 和 `解散` 是危险按钮。这一组里的其他按钮是安静按钮。

`看开始` 和 `看结束` 只改变忙闲板正在查看的时刻。它们不打开 S-06，也不写入。`现在` 把该时刻回到当前时间。`编辑` 按该事件 id 打开 S-06。没有事件的成员仍然看到忙闲板和 `新建事件`。

已移除的所有者所保留的团队可见事件留在事件列表中，并标出存储的电子邮件；该电子邮件没有成员行。查看者自己的行计入仅自己可见的事件。其他行只计入团队可见事件。

焦点按草图从上到下。忙闲板和事件列表先在表面内部滚动，然后才是窗口滚动。

## S-06 一个事件

操作者：正在创建或编辑自己可以更改的事件的当前成员，或者正在编辑一条保留的团队可见事件的文字、时间或删除的维护者。外壳保持不变。在保存、取消或 Escape 之前，这个表面替换 S-05 的主体。

创建：

```text
新建事件
可见性      ( ) 团队    ( ) 仅自己
标题        [________________________]
地点        [________________________]
描述        [                        ]
开始        [________________________]
结束        [________________________]
时区        {投影时区，只读}
[保存]  [取消]
结果行
```

创建者编辑使用同样的字段。已存储的时钟一开始是文字，并带有安静的 `更改开始` 和 `更改结束`。只有使用了对应的更改控件之后，那个时钟才变成 C-04。保存时，未更改的时钟不发送；正在补报发生时刻的那个时钟除外。

保管编辑不显示可见性选择，只把 `团队` 作为只读文字。标题、地点、描述、时钟和删除仍然保留。

开始时间含糊，或者两者都含糊时先处理开始时间：

```text
开始时间出现了两次。
( ) 较早
( ) 较晚
```

没有预选项。结束时间的问题只在开始时间的选择已经可以发送之后出现。这两个问题都不是新的目的地。取消、Escape 或放弃该选择都会回到 S-05，并且不写入。删除是危险按钮，出现在操作者可以删除的已有事件上；创建时没有删除。

## S-07 记录不可读

```text
这份团队记录无法读取。
不会创建替代团队。
```

只有 C-08。没有创建按钮。外壳的 `打开另一个会话` 仍然在。在日后批准修复之前，表面保持不动。

## 这些草图覆盖的状态

| 表面 | 草图中的变体 |
|---|---|
| S-01 | 空白、被拒绝的电子邮件、已绑定 |
| S-02 | 就绪、创建被拒绝 |
| S-03 | 待处理、命令失败、已接受、已拒绝 |
| S-04 | 无访问权 |
| S-05 | 有成员和事件、没有事件、维护者控件、唯一成员解散、名册操作被拒绝 |
| S-06 | 创建、编辑、保管、无效或不存在的时间、含糊时间、已取消 |
| S-07 | 不可用 |
| S-08 | 盖在当前表面上的通知 |

命令进行中时，该命令的按钮标签改为进行中的动词。草图不增加旋转指示。
