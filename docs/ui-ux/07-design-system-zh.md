# 设计系统

## 范围
轻量应用级规范，不建设通用组件平台。

## 设计令牌
记录语义颜色（背景/表面/正文/次级文字/边框/焦点/成功/警告/错误/忙/闲）、字体、间距/尺寸、圆角/边框/层级、动效及减少动态效果行为。

## 组件模式
仅定义获批页面需要的组件：应用外壳/导航、按钮、文本/邮箱/日期/时间输入、选择器/可见性控件、事件行/卡片和忙闲指示、成员/邀请列表项、对话框、校验/通知、加载/空/错误/无权限状态。

## 组件规格
记录用途、结构、变体、状态、键盘行为、无障碍名称/描述、缩放行为和使用示例。

## 无障碍基线
支持键盘操作和合理焦点顺序；焦点可见；提供程序化标签并关联错误；对比度充分；不得只用颜色表达忙闲/可见性/权限；尊重减少动态效果偏好。
