# 视觉设计

## 设计方向
选定方向为 **System-First、Linear-inspired**。Linear 是克制、精确、信息密度较高的桌面工具视觉参考，不是需要复制的目标产品。必须先结合仓库证据提出具体视觉方向，并由用户明确批准，之后才能确定最终 Token 值。

## 待评估的视觉特征
- 中性、低噪声的表面和克制的强调色策略。
- 清晰的字体层级和经过设计的信息密度。
- 精确对齐、一致间距、轻量分隔线和克制的层级阴影。
- 适合实际应用的稳定桌面导航/内容结构。
- 一致的图标体系、描边/尺寸、焦点样式和交互反馈。
- 忙闲和可见性区分清楚，且绝不只依赖颜色。

这些是设计假设，不是已批准的颜色、字体、尺寸或布局决策。

## 必需规格
记录获批方向、参考特征及来源、建议借鉴/避免的内容、信息层级、语义颜色及对比度、字体和截断、间距/密度、表面/边框/焦点、图标语义和文本替代、状态样式、桌面窗口行为。每项视觉决策都关联已批准 Token 和组件。

## 约束
不得复制 Linear 品牌、Logo、产品专属页面模式或受保护资产。不得暗示 PRD 未定义的业务状态。只有现有产品方向支持且用户批准时，才能定义浅/深色主题；不得增加主题偏好功能。完整品牌/营销识别不在范围内。页面级设计系统偏差必须记录并说明理由。
