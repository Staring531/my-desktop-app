# 视觉参考

- 状态：DRAFT，直到用户批准具体 Visual Direction。
- 已选参考类别：Linear-inspired 桌面效率工具/生产力工具界面。
- 本文记录视觉分析，不构成产品需求，也不授权复制第三方资产。

## 参考记录模板
每项参考记录：
1. 产品/来源名称和准确 URL。
2. 截图日期及相关页面/上下文。
3. 可观察特征（布局、层级、信息密度、字体、表面、颜色、图标、动效）。
4. 建议借鉴的特征及其适用理由。
5. 建议避免的特征及其理由。
6. 与实际桌面约束和已批准 PRD 流程的适配性。
7. 用户决策：PROPOSED / ACCEPTED / REJECTED，并记录日期/上下文。

## 初步方向假设
评估中性克制的表面、精确对齐、紧凑但易读的信息密度、清晰字体层级、轻量分隔线、克制强调色、一致图标和低干扰交互反馈。这些仅为假设。

## 护栏
- 不复制 Linear 品牌、Logo、专有资产或产品专属工作流。
- 不从参考产品推断深色模式、主题切换、命令面板、集成或其他功能。
- 参考截图仅用于启发和举证；可编辑规格和获批 Token 才是权威。
- Visual Direction Gate 必须由用户明确接受一个方向后，才能提出最终 Token 值。
