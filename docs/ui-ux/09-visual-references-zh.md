## 1. 这个门禁决定什么

用户于 2026-11-20 选择了方向 L。该选择允许提出 Token 和组件提案。它不批准这些数值，也不授权线框或高保真页面。

下面三个方向都只要浅色表面。它们都不增加主题偏好、深色主题、命令面板或新的产品表面。

忙碌与空闲、团队可见与仅自己可见，必须在不依赖颜色的情况下仍能分辨。这是已有约束，不是 Token。

若选择方向 L，建议借鉴：

- 整个窗口一个安静表面，区域靠对齐和细线分开，而不是靠盒子卡片。
- 成员和事件使用紧凑但可读的行，因为 S-05 是忙闲板加列表。
- 一种强调只留给主要操作或当前选中行，不用于区分忙碌和空闲。
- 命令结果显示在发出该命令的表面上，短而安静。

每个方向都避免：

- 把 Linear 的名称、标志、字标和专有品牌色当成这个产品的身份。
- 项目、议题、周期或收件箱的左侧栏。本产品没有这些对象。
- 命令面板、快捷键产品或集成陈列。
- 深色模式或主题开关。已批准范围没有主题偏好。
- 只用颜色表示忙碌、空闲、仅自己可见或失败。

## 3. 方向 L — 安静的仪器

建议选择这一项。它受 Linear 启发，但不是 Linear 的复制品。

| 主题 | 方向 |
|---|---|
| 姿态 | 给一个团队用的桌面仪器。窗口主要是工作区，不是宣传框。 |
| 密度 | 紧凑的行。成员列表和事件列表可以共用 S-05，而不再做一个导航产品。 |
| 层级 | 当前区域标题，然后是行内容，然后是上一条命令的结果。维护者操作次于忙闲板。 |
| 表面 | 浅色中性底。用间距和发丝线分隔。很少或不用阴影。 |
| 颜色策略 | 中性文字和表面。一种强调色只用于主要操作和选中行。忙碌、空闲、仅自己可见和错误同时使用文字或记号。 |
| 字体 | 一种无衬线家族。标题、行文和辅助信息是三种角色。不用展示型大标题。具体字体和字号等到 Stage 3。 |
| 图标 | 一小套简单记号，表示忙碌、空闲、仅自己可见和团队可见，每个都带文字标签。不用插画式图标。 |
| 动效 | 几乎没有。结果就地出现。没有入场编排。 |
| 适配 | S-05 和 S-06 最受益。S-01 到 S-04 用同一套系统，密度更低。 |

## 4. 方向 P — 敞开的纸面

| 主题 | 方向 |
|---|---|
| 姿态 | 一份安静的文档。更多空白，屏幕上的行更少，标题更大。 |
| 密度 | 疏松。忙闲板在操作者滚动之前显示的成员更少。 |
| 层级 | 页面标题占主导。操作远离列表。 |
| 表面 | 偏暖的中性纸色。区域是同一底上的带状区域，不是卡片。 |
| 颜色策略 | 几乎没有强调色。链接和主要操作用同一深色文字，加下划线或一个朴素按钮。状态用文字。 |
| 字体 | 行文用易读的文本字体，标题用另一种字体。具体字体等到 Stage 3。 |
| 图标 | 优先用文字。只有行内容会含糊时才用记号。 |
| 动效 | 没有。 |
| 适配 | S-01、S-02 和 S-06 较从容。对满员的忙闲板较弱，而忙闲板是产品的主视图。 |

## 5. 方向 C — 有格线的账册

| 主题 | 方向 |
|---|---|
| 姿态 | 一张画了线的表。忙闲板首先像账册，表单其次。 |
| 密度 | 高，但线比方向 L 更重，每一行都被线框住。 |
| 层级 | 列标题和数据一样强。事件列表使用同一套表格语法。 |
| 表面 | 白底、深色文字、可见的横线和竖线。没有阴影。 |
| 颜色策略 | 没有强调色相。选中用更重的线或一个标记字符。忙碌和空闲是文字加上实心或空心记号。 |
| 字体 | 时间用等宽数字。一种朴素无衬线。具体字体等到 Stage 3。 |
| 图标 | 标记字符和短词，不是一套图画图标。 |
| 动效 | 没有。 |
| 适配 | 适合比较时刻和成员。对事件表单偏重，对邀请页和无访问页不够安静。 |
