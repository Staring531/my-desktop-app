## 1. 如何阅读这三层

原始令牌保存具体值。语义令牌按用途命名，并指向原始令牌。组件令牌指向语义令牌；已经是原始尺寸的共用尺寸除外。以后的页面说明使用语义令牌或组件令牌。

只有一套浅色主题。没有深色值，也没有主题偏好令牌。

## 2. 颜色

页面底是 `#F6F7F8`。主要文字是 `#1A1D21`。唯一的强调色是 `#1E4E8C`，用于主要按钮、键盘焦点环和选中行的标记。它不用于公开、私密、`scheduled`、`skipped`、`choice_required`、冲突或失败。

| 组合 | 取值 | 设计时对比度 |
|---|---|---|
| 主要文字在底上 | `#1A1D21` 在 `#F6F7F8` 上 | 约 15.8:1 |
| 次要文字在底上 | `#3C4450` 在 `#F6F7F8` 上 | 约 9.2:1 |
| 辅助文字在底上 | `#4E5663` 在 `#F6F7F8` 上 | 约 6.9:1 |
| 强调色上的白字 | `#FFFFFF` 在 `#1E4E8C` 上 | 约 8.3:1 |
| 失败文字在底上 | `#8B2A22` 在 `#F6F7F8` 上 | 约 8.0:1 |
| 主要文字在选中浅底上 | `#1A1D21` 在 `#E7EEF6` 上 | 约 14.5:1 |
| 字段边在白色上 | `#5E6772` 在 `#FFFFFF` 上 | 约 5.7:1 |
| 字段边在页面底上 | `#5E6772` 在 `#F6F7F8` 上 | 约 5.4:1 |

这些比值使用 sRGB 相对亮度公式。它们是设计时的算术，不是认证审核。发丝线 `#D3D7DE` 分隔区域和行，不是文字颜色。字段边在白底和页面底上都达到 3:1。它不是状态色。

失败文字是第二条通道。看得见的词仍然是 API 的 `result`。`login_rejected` 这类共用失败在每个显示它的屏幕上使用同一种失败文字。

## 3. 字体、间距和形状

一套操作系统无衬线。三种角色：标题 18/24、字重 600；正文 14/20、字重 400；辅助文字 12/16、字重 400。没有网络字体，也没有展示用大标题。时钟时间和公历日在同一套字体里使用等宽数字。

间距阶梯是 4、8、12、16、24 和 32 像素。控件高 32 像素。出现行至少 32 像素，并随文字增高。控件圆角 4 像素，页面圆角 0。没有阴影。反馈时长是 0 毫秒，减少动效时也是这个值。

`size.content` 是 640 像素。它是页面内边距里的那一列任务区。更窄的视口使用视口减去这块内边距。这不是一套断点，也不是移动布局。

## 4. 使用规则

- PRD 区分的状态同时写出 API 用词：`public`、`private`、`scheduled`、`skipped` 或 `choice_required`。
- 强调色只标记主要动作和选中行。选中行还有一条 2 像素的前导条，因此浅底不是唯一线索。
- 失败使用失败文字加上 `result` 字符串。它不引入第二种填充色，也不解释哪个值被占用，或账户是否存在。
- 成功的命令按返回正文重绘。`conflicts` 是 `title`、`start` 和 `end` 的行。`continuesAfterWindow: true` 是单独的一句：重复在 90 天之后继续。这句话不是冲突条目，也不是失败文字。
- 没有新的提案时，不增加阴影、第二种强调色、深色主题，或 `motion.feedback` 以外的动效时长。
- JSON 里的别名是唯一的间接引用。存在语义颜色时，页面不直接指向原始颜色。
