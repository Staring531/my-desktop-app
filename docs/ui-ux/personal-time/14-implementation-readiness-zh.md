## 2. 实现时会约束呈现的决定

这些只在用户批准这套文稿之后约束呈现。它们现在还不约束实现。

- 一条浅色列，`component.page.content-max` 位于 `component.page.inset` 之内。没有主题开关、导航轨、月网格、搜索、分享、团队或他人的日历。
- 任务标题是表面名称。Q-03 开放，因此没有产品标题替换脚手架文档标题。
- Q-04 开放。From 和 To 开始为空，两个都键入之前 Show range 不发送。
- Q-02 开放。邮件没有设计。S-02 和 S-06 提交证明码。
- 命令在途时显示 `waiting`，按钮标签保持不变，并且不再次发送。`waiting` 不是 API 结果。
- 留在原页时显示字符串 `ok`，没有第二句成功说明。S-02 和 S-06 在 `ok` 时打开 S-04。S-04 在 `ok` 时打开 S-07。没有会话的受保护路径画出 S-04 和 `logged_out`。
- 创建时的 Save 在选中一种重复之前是安静的。不重复选项发送 `none`。
- 开始和结束是键入的公历日和时钟，按输入发送。
- 删除在 PT-C10 的危险按钮之前不发送。取消不发送。
- 共用失败显示 `result` 字符串，不说明哪个值被占用。
