## 1. 这一关决定什么

用户于 2026-11-25 选定 Direction L。该选择授权之后提出令牌和组件方案。它不批准那些取值。

三个方向都只有浅色表面。都不增加主题偏好、深色主题、命令面板，或 S-01 至 S-09 之外的目的地。

公开和私密、`scheduled`、`skipped` 和 `choice_required` 必须不依赖颜色也能看懂。`login_rejected` 这类共用失败在每个显示它的屏幕上必须看起来相同。这些约束来自已批准的 PRD，不是令牌。

## 2. 参考记录

| 字段 | 记录 |
|---|---|
| 来源 | Linear 的公开产品网站 `https://linear.app` |
| 采集 | 这次没有采集。仓库里没有截图文件。 |

| 这里采用的可观察意图 | 紧凑的行、安静的表面、少量动作与密集记录分开、用轻微分隔而不是厚重卡片。 |
| 归属 | 参考是上面的公开网站。本产品不采用 Linear 的名称、标志、字标或品牌色。 |

若选择 Direction L，建议采用的特征：

- 页面是一整片平静的底。区域靠对齐和细线分开，不靠盒子卡片。
- S-07 上的出现用紧凑的行，因为该页显示的是一段返回对象。
- 一种强调色只留给当前动作或选中的行，不留给可见性或出现状态。
- 命令的 `result` 以短文出现在发出该命令的页面上。

每个方向都避免：

- 把 Linear 的名称、标志、字标和品牌色当作本产品的身份。
- 项目、议题、周期或收件箱的侧栏。本产品没有这些对象。
- 命令面板、营销首页或集成陈列。
- 深色模式或主题开关。已批准范围没有主题偏好。
- 只用颜色表示公开、私密、跳过、需要选择、冲突或失败。
- 月网格、周网格，或对初始 `from` 和 `to` 的任何选择。Q-04 仍开放。线框在本关之后。

## 3. Direction L — 安静的工具

推荐选择这一套。它受 Linear 启发，但不是 Linear 的复制品。

| 主题 | 方向 |
|---|---|
| 姿态 | 一个人的日历所用的浏览器工具。页面主要是当前任务，不是宣传框。 |
| 密度 | S-07 用紧凑的出现行。S-01 至 S-06 和 S-09 是同一系统里的短表单。 |
| 层次 | 任务标题，然后是字段或行，然后是上一条命令的 `result`。账户和事件动作次于日历。 |
| 表面 | 浅色中性底。用间距和发丝线分隔。很少或没有阴影。 |
| 颜色策略 | 中性的文字和表面。一种强调色只用于主要动作和选中的行。可见性、出现状态、冲突和失败同时使用文字。 |
| 字体 | 一套无衬线。标题、行或字段文字、辅助文字是三种角色。没有展示用大标题字体。具体字体和字号等到 Stage 3。 |
| 图标 | 一小套简单标记，表示公开、私密、跳过和需要选择，每个都带上 API 状态的文字。没有插画式图标。 |
| 动效 | 几乎没有。结果就地出现。没有入场编排。 |
| 契合 | 适合 S-07 和 S-08 上的冲突列表。无需会话的表单保持安静，不变成另一套营销系统。 |

## 4. Direction P — 开阔的纸面

| 主题 | 方向 |
|---|---|
| 姿态 | 一份安静的文档。更多空白，一次能看见的行更少，标题更大。 |
| 密度 | 疏松。S-07 在用户移动范围之前显示更少的出现。 |
| 层次 | 页面标题占主导。动作离开行，单独放置。 |
| 表面 | 暖中性纸色。区域是同一底上的色带，不是卡片。 |
| 颜色策略 | 几乎没有强调色。主要动作用同样的深色文字，加下划线或朴素按钮。状态用文字。 |
| 字体 | 字段和行用易读的正文字体，标题用另一套字体。具体字体等到 Stage 3。 |
| 图标 | 优先用文字。只有行否则会含混时才用标记。 |
| 动效 | 没有。 |
| 契合 | 适合 S-01 至 S-06 和 S-08。对 S-07 较弱，而 S-07 是登录后回到的页面。 |

## 5. Direction C — 画线的账册

| 主题 | 方向 |
|---|---|
| 姿态 | 一张画了线的表。S-07 首先像账册，然后才像表单。 |
| 密度 | 高，线条比 Direction L 更重，每次出现都被线框住。 |
| 层次 | 列标题和数据一样强。S-08 的字段使用同一套画线语法。 |
| 表面 | 白底、深色文字、可见的横线和竖线。没有阴影。 |
| 颜色策略 | 没有强调色相。选中用更重的线或一个标记字符。可见性和出现状态是文字加标记。 |
| 字体 | 时钟时间用等宽数字。一套朴素无衬线。具体字体等到 Stage 3。 |
| 图标 | 标记字符和短词，不是一套图画图标。 |
| 动效 | 没有。 |
| 契合 | 适合比较出现和冲突时间。对 S-01 至 S-06 偏重。 |
