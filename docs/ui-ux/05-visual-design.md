# Visual Design

## Goals
Create a restrained desktop visual language supporting scanning, event comparison, and safe permission-sensitive/destructive operations.

## Specification
Define hierarchy; semantic color roles and contrast; typography and truncation; spacing/density; surfaces/borders/focus; icon semantics and text alternatives; busy/free visualization; and resize behavior.

## Constraints
Busy/free and visibility must not rely on color alone. Do not imply business states absent from the PRD. Define light/dark theme behavior only if supported by existing product direction; do not invent a theme-preference feature. Full branding/marketing identity is out of scope.
