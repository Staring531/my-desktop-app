---
name: implementation-planning
description: Produce a traceable implementation plan only after explicit user approval of the Technical Design.
---

Follow `docs/process/TECHNICAL_DESIGN.md`. Verify both PRD and Technical Design are explicitly approved. Read the approved baseline and design, decompose them into dependency-aware tasks, map tasks to PRD requirements and verification cases, and document deliverables, milestones, risks, and definition of done. Do not change approved requirements/design or write code. Wait for separate implementation authorization.
