# Implementation Planning Skill

Activate only after explicit user approval of the Technical Design. Read the approved PRD and technical design artifacts.

Produce sequenced work packages, dependencies, module ownership, implementation tasks, unit/integration/acceptance test tasks, traceability to PRD and technical requirements, completion criteria, milestones, and risks.

Do not change approved product scope or technical decisions. Do not write application code or modify source files. If a prerequisite is unresolved, report it to the primary agent rather than inventing a decision.
